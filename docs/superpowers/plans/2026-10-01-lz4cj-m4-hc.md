# lz4cj M4 实现计划(HC 高压缩:三策略全级别 + 流式 + 字典 + destSize)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移植 lz4hc.c 全部非弃用 API(lz4mid 级 1-2 / 链表级 3-9 / 最优解析级 10-12 三策略 + 流式 + 字典 + destSize),压缩输出与 C golden 逐字节一致(levels 1-12 全采样),全部经既有解压器闭环往返,双工具链全绿。

**Architecture:** `LZ4_streamHC_t` 以双段引用对模型承载(prefix = (prefixBuf, prefixStartIdx, prefixEndIdx) + dictLimit 虚拟基;extDict = (dictBuf, dictStartIdx) + lowLimit 虚拟基;U32 虚拟索引空间),与 §4.3 规则 4 及 M3a 解码侧先例同构;C 的 `src == end` 指针相等分派以 `lz4SameBuffer`(M3b 双哨兵探针)实现;三策略核心各为独立内函数,共享 `LZ4HC_encodeSequence` 与链表搜索机。

**Tech Stack:** Cangjie LTS-1.0.5 / STS-1.2.0、cjpm、cc(C golden/探针)、std.unittest。

**Spec:** `docs/design.md`(§4.5 HC 清单、§5.4、§8.2 golden 矩阵、§10 M4 行、附录 12 第 7 条)。关联:`docs/progress.md` M4 分解。
